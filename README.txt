INS 壁纸轮播器 v2.6 · 使用说明
================================

【这是啥】
一个 Windows 小软件，把 Instagram 上你喜欢的账号、本地文件夹、或你手动选的
单张图片，自动轮播成你的电脑桌面壁纸。
仅限个人自己看，请勿打包分发或商用（图片版权归原作者）。

【五种图片来源】
  IG 账户(IG)      : 粘贴 Instagram 链接，软件自动抓取该账号图片
  歌手(歌手)       : 输入歌手名（如 Yorushika / 周杰伦），自动抓该歌手全部专辑封面当壁纸，
                     并可用内置「音乐播放器」播放 TA 的歌（数据来自 GD 音乐台公开 API，仅供学习）
  本地文件夹(文件夹): 引用一个本地图片文件夹（不复制，实时读取，文件夹里增删图会立刻生效）
  本地单张(本地)    : 手动一张张选图片，归集到一个“本地单张”来源里轮播
  随机图(内置)     : 内置几个免费API随机好图(Picsum / Bing 壁纸镜像)，点「导入随机图(内置)」
                     即可，免 key、无版权风险，适合做纯欣赏壁纸

【怎么用】
1. 双击 InsWallpaper.exe 打开。首次启动稍慢（要解压内置浏览器），请耐心等几秒。
2. 导入图片来源（三种任选）：
   - 导入 IG 账户：在「IG 链接」多行框里每行粘一个账号主页，例如
       https://www.instagram.com/kasumi_arimura.official/
     然后点「批量导入账户」。软件会用 igram.world 逐个抓取（每行一个独立进度）。
   - 导入文件夹：点「导入文件夹」，选一个装图片的目录即可（图片不复制，直接引用）。
   - 导入单张：点「导入单张」，选一张或多张图片，会归集到“本地单张”来源。
   - 导入随机图(内置)：点「导入随机图(内置)」，从内置免费API(Picsum / Bing 壁纸镜像)拉一批
     随机好图作壁纸来源，免 key、无版权风险；点该来源的「刷新」可换一批。
   - 歌手(专辑壁纸)：在「歌手(专辑壁纸)」输入框输入歌手名，点「导入该歌手专辑」，
     软件会用 GD 音乐台 API 搜该歌手、去重出全部专辑、把每张专辑封面下载到壁纸池
     （增量保留，不删旧图）。点来源行的「打开播放器」会用默认浏览器打开内置音乐播放器
     并自动播放该歌手；也可直接在输入框右侧点「打开音乐播放器」（可留空=只开播放器）。
     在播放器里点「💿 下载此歌手全部专辑做壁纸」还能把封面打包下到“下载”目录。
   - 音乐播放器增强（v2.6，玩家更顺手）：
       · 搜索结果里每首歌右侧有「⋯」按钮，可一键：
           下载这首歌曲 / 下载整张专辑 / 下载该歌手全部歌曲（会弹窗询问是否把
           歌词+封面“烧录”进音频文件）/ 加此封面做壁纸 / 加全部专辑封面做壁纸。
           其中“加壁纸”逻辑与壁纸软件一致（封面命名 album_<pic_id>.jpg、增量保留、
           并导出清单 JSON 供导入）；在壁纸软件里对该歌手点「导入该歌手专辑」即可生效。
       · 播放时屏幕底部有「实时悬浮歌词」（右下角按钮可开关），跟随进度高亮当前句。
   - 统一刷新：导入区右侧「统一刷新所有IG」按钮，一次性错峰刷新全部 IG 账户
     （等价于把每个 IG 账户逐个点“刷新”），省得一个个点。
   - 刷新间隔(秒)：统一刷新时，各账户按此间隔依次启动（默认 20 秒），避免同一秒
     所有请求一起打向 igram.world 被服务器限速/锁死。设为 0 则不等。
   - 最多抓取(张)：每个 IG 账户最多下载多少张（默认 0=全部）。账号帖子很多时，
     设个小数字(如 20)能更快抓完、少占空间；设 0 则抓该账户全部帖子。
3. 导入完成后，来源出现在下方列表，并自动勾选。
4. 设置轮播：
   - 间隔(秒)：每张壁纸停留多久（默认 30 秒）
   - 顺序：随机 / 顺序
   - 填充方式（重要）：
       铺满(不变形)【默认】：等比放大铺满屏幕，裁掉溢出部分，无黑边、不变形。
                           这是 2.4 的新默认——之前“一大坨黑边”的问题靠它解决。
       适应(黑边)      ：整图等比缩放放进屏幕，四周补黑边，绝不裁切、绝不拉伸。
                           此模式下“发布日期”会烧录在黑边角落（桌面可见）。
       居中            ：图片小于屏幕时按原尺寸居中（不放大）；大于屏幕时等同“适应”
       平铺            ：原图重复铺排
       拼贴(16:9)【新增】：把多张同来源图片拼成一张刚好填满 16:9 屏幕的网格，
                           每张在自己的格子里做轻微 cover 裁切，整图无黑边、不变形、
                           不浪费，一次还能看多张（适合没有 16:9 竖图的情况）。
                           配合下方“拼贴张数”(2~9)使用。
   - AI 超分(显卡,4×)（新增，可选）：勾选后用本地 Real-ESRGAN(NCNN/Vulkan) 对每张
     壁纸做 GPU 超分（固定 4×，照片模型 realesrgan-x4plus），把低清图补到 2K/4K 再设壁纸。
     结果按原图缓存（下次直接用，不重复算）；要求显卡支持 Vulkan，若不可用会自动回退原图。
     注意：超分只在“设壁纸”时做一次，不是每帧实时算，所以不影响轮播流畅度。
   - 拼贴张数（新增）：填充方式选“拼贴(16:9)”时，用这么多张图拼满屏幕（2~9，默认 4）。
   - 轮换跨度：只轮换“最近这段时间”内发布的照片，可选
        永久（全部） / 1年 / 20天 / 10天
     例如选“10天”，就只轮播该账户最近 10 天发的图，更老的自动跳过。
   - 轮播时自动更新IG（更新与轮换合一）：勾选后，轮播过程中会按“每 N 小时”
     自动重新抓取所有 IG 账户（同样走错峰限速），不用你手动去点刷新。
     不勾则保持旧行为，纯轮播已下好的图。
5. 点「开始轮播」，壁纸就开始自动换了；点「停止」结束。
6. 状态栏会显示“当前壁纸: 文件名 宽x高 · 发布 2026-07-20”，可看到尺寸与发布日期。
   用“适应(黑边)”铺法时，发布日期还会直接烧录在壁纸黑边角落（桌面可见），绝不裁切照片。
7. 每个 IG 账户下方会列出“最近更新(按天)”：该账户最新几张图的发布日期，一眼看它近期发图情况。
8. 按 F12 随时打开“报错查看”窗口，里面是崩溃日志(app_error.log)与本次运行日志，方便排查。

【每日时段轮播（重点功能）】
每个来源（IG / 文件夹 / 本地单张）右侧都有「时段」两个框：开始 - 结束（24 小时制 HH:MM）。
  - 留空 = 不限时段，全天参与轮播。
  - 填了时段 = 只在每天该时间段内参与轮播，其余时间不出现在壁纸里。
  - 支持跨午夜：如 23:00 - 08:00 表示晚上 11 点直到次日早上 8 点。
  - 勾选多个来源并给它们设成相同时段，就能实现“同一时段轮播多个账户/文件夹”。
  - 修改时段后自动保存，无需额外点按钮。
  - 若当前时间没有任何来源的时段命中，软件会显示“当前时段无活跃来源，等待中…”，
    并每 60 秒检查一次，到时间自动恢复轮播。

【多来源】
- 可同时导入多个 IG 账户、多个文件夹、以及本地单张集合。
- 只勾选你想轮播的来源，软件会从所有勾选且“当前时段命中”的来源里随机取图。
- 账户行按钮：
    刷新 = 重新抓取“该”账户最新图片
    打开播放器 = 仅歌手来源有；打开内置音乐播放器并播放该歌手（GD 音乐台 API）
    导入图片 = 手动把你自己下载好的图片加进该来源（IG / 本地单张都可用）
    删除 = 移除该来源及其已下载图片
- 顶部「统一刷新所有IG」按钮 = 一次性并行刷新“全部” IG 账户（懒得一个个点时用）。

【抓不到 IG 图怎么办】
- 第三方抓取源 igram.world 偶尔不稳定。点账户行的「刷新」重试即可（内置 3 次重试）。
- 或点账户行的「导入图片」，手动把你自己下载好的 IG 图片添加进来（照样能轮播）。
- 各 IG 账户图片存在：
    C:\Users\你的用户名\AppData\Local\InsWallpaper\accounts\ 下。
- AI 超分若提示“找不到模型/显卡不支持”，请确认本机显卡驱动支持 Vulkan；
  失败时软件会自动使用原图，不影响正常轮播。

【配置保存】
- 所有来源、勾选状态、时段设置、轮播参数（含画质/超分/拼贴）都会自动存到：
    C:\Users\你的用户名\AppData\Local\InsWallpaper\config.json
- 下次打开软件自动恢复，无需重新导入。

【关于仓库里的二进制依赖】
本仓库是**源码仓库**，已通过 .gitignore 排除大体积二进制，因此不包含：
  - dist/InsWallpaper.exe（打包产物，自行用 build_exe.py 生成）
  - realesrgan/ 目录（超分引擎 realesrgan-ncnn-vulkan.exe 及其模型 *.bin/*.param）
若要本地运行超分功能，请自行从 Real-ESRGAN 官方仓库下载
`realesrgan-ncnn-vulkan` 并解压到 realesrgan/ 下（保持 realesrgan-ncnn-vulkan.exe
与 models/realesrgan-x4plus.bin|param 的相对结构）。不放置也能用，只是"AI 超分"会回退原图。

【文件说明】
- InsWallpaper.exe  —— 软件本体（双击即用，已内含 Real-ESRGAN 超分引擎与音乐播放器 HTML）
- wallpaper_app.py   —— 源码（想改可自行修改后用 build_exe.py 重新打包）
- music_player.html  —— 内置音乐播放器（GD 音乐台 API，搜索/歌手/专辑/歌词，含「⋯」下载菜单、烧录歌词+封面、实时悬浮歌词、下载此歌手全部专辑做壁纸）
- build_exe.py       —— 打包脚本（需先 pip install pyinstaller playwright，且本机已 playwright install chromium）
- realesrgan/        —— 本地超分引擎与模型（已打进 exe，无需单独部署）
